# Registro de assets

Todo asset (imagem, sprite, CG, música, efeito, fonte) entra aqui antes de ser usado no jogo.
Para imagens geradas por IA, registre a ferramenta e confira os termos de uso dela.

**Como preencher uma linha:** quando o arquivo existir, troque os campos "a definir" por: a
ferramenta e a data da geração (ou a fonte e o link, se for pacote pronto), a licença, e se o uso
comercial é permitido. Depois mude o status para `pronto`. O prompt de cada cenário está em
`guia-de-arte.md`.
